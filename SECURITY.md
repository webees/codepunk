# Security Policy

## Supported versions

Codepunk is pre-1.0. Security fixes land on `main` and in the latest published release only.

## Reporting a vulnerability

Report privately through GitHub's [security advisory form](https://github.com/webees/codepunk/security/advisories/new). Do not open a public issue for undisclosed vulnerabilities.

Include the affected version, platform, reproduction steps, and impact. Expect an initial response within seven days; coordinated disclosure is preferred.
